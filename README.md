# Physics 355 — Continuity equation

Interactive browser simulation for 1-D Potentials Lesson 5 (potential step): free Gaussian wave packet with a movable window \([a,b]\), live comparison of \(\mathrm{d}P/\mathrm{d}t\) with \(J(a)-J(b)\), and an overlay of \(\partial\rho/\partial t\) against \(-\partial J/\partial x\).

**Live demo:** https://gkleiban.github.io/physics355-continuity-equation/

Open `index.html` locally in any browser — no install, no CDN.
